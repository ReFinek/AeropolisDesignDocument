# 📘 Демонстрация возможностей Markdown

Это вводный абзац. Markdown позволяет писать чистый, читаемый текст, который легко конвертируется в HTML, PDF или другие форматы. Ниже представлены основные элементы разметки.

---

## 📑 Заголовки

Поддерживается до 6 уровней вложенности:
## Заголовок H2
### Заголовок H3
#### Заголовок H4
##### Заголовок H5
###### Заголовок H6

> 💡 *Рекомендуется использовать H1 только один раз на странице.*

---

## ✍️ Форматирование текста

- **Жирный текст** (`**жирный**` или `__жирный__`)
- *Курсив* (`*курсив*` или `_курсив_`)
- ~~Зачёркнутый текст~~ (`~~зачёркнутый~~`)
- `Встроенный код` (`` `код` ``)
- ==Выделение== (`==выделение==` ⚠️ поддерживается не во всех парсерах)
- Ссылка с пояснением: [Документация CommonMark](https://commonmark.org/ "Перейти на сайт")

## 📋 Списки

### Неупорядоченный список
- Первый элемент
- Второй элемент
  - Вложенный пункт 2.1
  - Вложенный пункт 2.2
    - Третий уровень вложенности
- Третий элемент

### Упорядоченный список
1. Шаг первый
2. Шаг второй
   1. Подшаг 2.1
   2. Подшаг 2.2
3. Шаг третий
